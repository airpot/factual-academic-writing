# Factual Academic Writing · 事实驱动写作

**正式版：0.4.0。** 将学术写作的准确、论证、连贯和结构要求用于所有 AI 文字输出：日常解释、教学、操作说明、技术分析、建议、学术写作及创作。

按任务与读者选择形式，先给清楚的答案或动作，再组织必要的解释。检查句意、句间关系、段落作用和篇章结构；交代陌生编号的背景，合并重复限定，保留有用的说明和专业表达。去 AI 味以理解与表达质量为目标，不追求禁词清零或检测分数。

## 使用

- **起草**：形成所需回答或正文，区分事实、推断、建议与假设，纠正新回答中的错误。
- **编辑**：按所需深度改善表达，保留原意、立场、条件、否定、数字和引文；证据修正另列。
- **审查**：定位支持问题、冲突、修订建议和实际检查范围；审查不自动授权重写。

默认在五次尝试内完成至少三轮完整复核，最后两轮对同稿无已接受或待决问题。失败、中断和输入变化均如实计数；达到上限仍有问题则交付待审结果，不另起循环重置预算。小型任务无需正式日志，用户可明确要求降低复核深度。

## 安装与默认规范

从 [v0.4.0 发布页](https://github.com/airpot/factual-academic-writing/releases/tag/v0.4.0)下载技能 ZIP 并核对 SHA-256。将完整 `factual-academic-writing/` 目录放到 Codex 用户技能目录 `%USERPROFILE%\.agents\skills\`。保留全部参考资料与脚本；同名旧安装先备份。

显式调用 `$factual-academic-writing`，提供任务、材料及所需形式。Codex 会发现新安装；若列表未更新，可重启。

要设为 Codex 全局文字规范，先备份 `%USERPROFILE%\.codex\AGENTS.md`，再把 [default-policy.md](references/default-policy.md) 的完整正文追加到该文件。完整正文直接加载，不能仅靠一个文件路径或安装目录保证默认执行。已有全局规则应保留；有 `AGENTS.override.md` 时应先核对实际生效文件。新的运行加载更新后的全局指令，项目与用户的更具体要求仍适用。

## 例子与检查

“解释这段流程，让新人能找到下一步，保留全部条件。”

“压缩这份方案，先给建议，再说明依据；不要重复限定，也不要改变结论力度。”

“仅润色这一段，保持数字、否定、条件和引文；证据问题另列。”

见 [完整入口](SKILL.md)、[20组示例](references/writing-examples.md)及 [变更记录](CHANGELOG.md)。可选中文扫描器只依赖 Python 标准库：`python scripts/scan_ai_patterns.py manuscript.txt`。它提供语言模式提示，不能判断作者身份、来源真伪或写作是否合格。

## 验证边界

本轮使用中英文合成任务、独立模型审阅和实际读者反馈。当前24份交付稿通过语义与任务约束审阅；两份按反馈修订的样稿获同一读者确认更清楚。任务长度要求也作了修正，两份稿另有协调者编辑，因此不据此宣称仅靠 skill 就有普遍改善。模型理解题、真人反馈、源码检查和实际加载分别记录。多轮复核不保证零错误。

本仓库仅分发独立安装树；开发、失败与修复证据保留在统一源码工作区。0.3.2及旧标签保持原样。
